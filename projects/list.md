# «Лист»

**Telegram-бот и Mini App для саморефлексии** · [Открыть @list_reflection_test_bot](https://t.me/list_reflection_test_bot) · [Вернуться в профиль](../README.md)

## Задача

Мысли, планы и состояние часто оказываются в разных местах: заметки в телефоне, список задач отдельно, важные выводы теряются в переписке. «Лист» собирает эти действия в одном личном пространстве. Он помогает регулярно возвращаться к своим записям и замечать связь между состоянием, целями и следующими шагами.

## Возможности продукта

- **Дневник:** записи для свободной рефлексии и сохранения важных мыслей.
- **Отметки состояния:** настроение и энергия, которые можно фиксировать без длинного текста.
- **Цели и задачи:** место для намерений и конкретных действий.
- **AI-диалог:** обсуждение записей и планов с учётом доступного контекста пользователя.
- **Контроль данных:** просмотр сохранённой памяти, экспорт и удаление личных данных.

Telegram-бот служит точкой входа, а Mini App даёт интерфейс для работы с дневником и планами. Небольшой ежедневный шаг проще встроить в привычное приложение, чем начинать каждый раз в новом сервисе.

## Реализация и границы

По локальным материалам проекта подтверждены React, Vite и JavaScript для интерфейса; Python, FastAPI, SQLAlchemy и PostgreSQL для серверной части; Docker для развёртывания. Сервер проверяет данные, переданные Telegram, и разделяет данные пользователей. Для проекта предусмотрены автоматические проверки.

Бот публично обозначен как тестовый продукт для аудитории 18+. Это инструмент для саморефлексии, не медицинская помощь. Часть новых функций развивается в локальном прототипе, поэтому перечень возможностей опубликованной версии может отличаться. Исходный код и личные данные пользователей здесь не размещены.

**Что показывает проект:** разработку продукта с клиентской и серверной частью, Telegram-интеграцию, работу с личными данными, AI-функциями и полноценным пользовательским сценарием за пределами обычного лендинга.
